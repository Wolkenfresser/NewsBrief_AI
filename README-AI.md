# README-AI.md — правила AI-assisted разработки NewsBrief AI

## Назначение проекта

NewsBrief AI — медиасервис, который формирует краткую русскоязычную аннотацию новостной статьи для ленты. Аннотация служит черновиком: редактор должен проверить факты, даты, имена, числа и смысл по первоисточнику.

## Разрешено

- Создавать HTTP DTO в пакете `dto`, а REST-контроллеры — в `controller`; валидировать вход через Jakarta Bean Validation.
- Размещать бизнес-логику и сборку промпта только в `service`.
- Вызывать LLM только через `AiGateway`; реализовывать провайдеров через интерфейс `LlmClient`.
- Добавлять альтернативных провайдеров без изменения `ArticleSummaryService`.
- Добавлять метрики/логи, не содержащие исходный текст статьи, ответ модели, ключи, IAM-токены и заголовки авторизации.
- Создавать unit-тесты с JUnit/Mockito и интеграционные тесты через `@SpringBootTest` / `MockMvc`.
- При изменении API обновлять DTO, тесты, README, Swagger/OpenAPI-контракт и интерфейс React.
- Хранить параметры окружения в `application.yml` через `${ENV_VAR:default}`; по умолчанию система должна запускаться в demo-режиме.

## Запрещено

- Встраивать секреты в код, `application.yml`, `.env.example`, отчёты, frontend или тестовые фикстуры.
- Вызывать Yandex API, `RestClient`, другие внешние HTTP-сервисы из Controller или React напрямую.
- Переносить бизнес-правила в контроллеры.
- Логировать содержимое статей, промпты/ответы модели или персональные данные.
- Считать ответ LLM достоверным только потому, что он грамматически корректен.
- Добавлять к статье непроверенные факты, источники, даты, числа или выводы.
- Отключать Bean Validation, Retry/Circuit Breaker, тесты или обработку ошибок ради «зелёной» сборки.
- Удалять или ослаблять существующие тесты ради совпадения с реализацией.
- Возвращать клиенту stack trace, имена внутренних классов, тела исключений внешнего провайдера или реквизиты.
- Менять публичный контракт `POST /api/articles/summarize` без изменения DTO, тестов, Swagger и документации.

## Границы архитектуры

`ArticleSummaryController → ArticleSummaryService → AiGateway → YandexInvoker → YandexAgentClient`.

`AiGateway` — единственная точка маршрутизации. `InternalLlmClient` используется как локальный demo-провайдер и как fallback. Провайдеры не должны знать о REST DTO, HTTP-контроллере или frontend. Не объединяйте DTO и конфигурационные классы с кодом интеграции.

## Стандарт ответа

- Русский язык, нейтральный редакционный тон.
- Аннотация строго основана на входном тексте; не добавлять внешние сведения.
- Сохранять существенные факты и атрибуцию: кто, что, где и когда сообщил.
- Отделять факт от предположения; не превращать планы в свершившиеся события.
- Предпочитать ясность и точность эффектной формулировке.
- Добавлять тезисы только по запросу и только если текст содержит достаточные факты.

## Перед завершением изменения

1. `mvn test`.
2. `cd frontend && npm run build`.
3. Проверить отсутствие секретов и текстов статей в логах.
4. Убедиться, что UI показывает режим demo/fallback и не выдаёт локальный эвристический результат за ответ внешней LLM.
5. Если поменялся API — обновить примеры в README и интеграционные тесты.
