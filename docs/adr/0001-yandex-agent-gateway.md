# ADR-0001: AI Gateway и Yandex AI Studio для NewsBrief AI

- **Статус:** принято
- **Дата:** 2026-10-27
- **Контекст:** лабораторная работа № 1, вариант 13 — генерация аннотации статьи для новостной медиаплатформы.

## Решение

Бизнес-логика обращается к `AiGateway`, а не к внешнему API напрямую. Провайдеры реализуют `LlmClient`. Основной удалённый адаптер — `YandexAgentClient`, работающий с Responses API Yandex AI Studio. В обычном режиме обязательны `YANDEX_FOLDER_ID` и `YANDEX_MODEL`; необязательный `YANDEX_PROMPT_ID` ссылается на сохранённый prompt-шаблон Responses API. API-ключ передаётся через `YANDEX_API_KEY`, IAM-токен — через `YANDEX_IAM_TOKEN`; секреты не хранятся в репозитории.

При отсутствующих реквизитах или ошибке удалённого провайдера Gateway использует `InternalLlmClient`. Он формирует детерминированный демонстрационный пересказ на основе предложений исходной статьи. В API ответе явно устанавливается `fallbackUsed=true`, а интерфейс предупреждает, что результат создан локально. Это сохраняет демонстрационную пригодность приложения без выдачи локального алгоритма за внешнюю модель.

Для удалённого вызова заданы HTTP timeouts, ограниченный Retry и Circuit Breaker Resilience4j. Статистика собирается в Micrometer/Actuator; логи не включают текст статьи и ключи.

## Альтернативы

1. **Вызов Yandex из контроллера:** отклонён, так как нарушает разделение слоёв и усложняет тестирование.
2. **Один жёстко встроенный клиент:** отклонён из-за vendor lock и отсутствия fallback.
3. **Обязательный API-ключ для запуска:** отклонён, так как делает frontend/REST демонстрацию недоступными в аудитории без настроенных реквизитов.
4. **Полностью случайная заглушка:** отклонена; локальный режим должен возвращать воспроизводимый результат, связанный с исходным текстом.
5. **Включённый web search при каждом запросе:** отклонён для этой задачи, так как краткая аннотация должна сохранять содержание предоставленной статьи, а не дополняться внешними фактами.

## Последствия

- Приложение можно запускать без ключа и проверять API/UI в demo-режиме.
- Для реального агента требуются действительные credentials и доступ/роли Yandex AI Studio.
- Локальный fallback — простая эвристика, не заменяющая LLM и редакторскую проверку.
- Для production потребуются rate limits, управление бюджетом/квотами, аудит, более строгая оценка качества и мониторинг ошибок.
